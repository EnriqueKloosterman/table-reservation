# Table Reservation — Backend

## Overview

HTTP JSON API for a single restaurant: staff sign-in (JWT), tables, weekly service hours and
closed dates. Express 5 + Mongoose + Zod, strict TypeScript (ESM).

## Requirements

- Node.js 24 LTS (minimum 22.12)
- MongoDB (tests use mongodb-memory-server and need no running database)
